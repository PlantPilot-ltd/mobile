# Project brief — mobile

Flutter app of the PlantPilot smart-greenhouse platform (repo `PlantPilot-ltd/mobile`,
workspace folder `frontend/mobile`). Users find PlantPilot controllers over Bluetooth LE,
add them as greenhouses, and manage greenhouses and plants; data comes from a server over HTTP.

## Current scope
- Bluetooth device list → add greenhouse → greenhouses list (in progress).
- Greenhouse and profile screens (early).

Product context (users, UX goals) is shared: root `.agent/memory_bank/product_context.md`.
