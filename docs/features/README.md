# Feature descriptions — PlantPilot mobile

Features that touch **only this project**, written in product language by the owner.
Features spanning several projects go to the workspace root `docs/features/` instead.

- File name = feature name in `snake_case`: `<name>.md`, from [`_template.md`](_template.md).
- Then tell the agent: _"start feature `<name>`"_ — it tracks the work in `features/<name>/`.
- This file is the **source of truth**; if you change it, the agent re-syncs the requirements.
